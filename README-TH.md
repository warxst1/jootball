# Jootball — ส่งมอบงานสแกนพาสปอร์ต

เทียบไฟล์กับ branch ของบริษัทก่อนนำเข้า โดยเฉพาะ manage.php ที่มีทั้งฟอร์มสแกน ภูมิลำเนา และข้อความเมื่อบันทึกไม่สำเร็จ ให้รวมเฉพาะส่วนที่เกี่ยวข้องหากไฟล์ในบริษัทมีการแก้เพิ่มเติม

- modules/Player/Views/manage.php — UI ถ่ายรูป เลือกรูป ดูภาพก่อนสแกน และฟอร์มนักเตะ
- public/js/passport-scan.js และ public/js/passport-ocr/ — อ่าน MRZ ในเบราว์เซอร์ ตรวจ Check Digit และเติมฟอร์ม
- public/js/bootstrap.bundle.min.js, public/js/select2.min.js และ public/css/select2.min.css — สำเนาไฟล์ที่กู้คืนใน XAMPP ใช้เมื่อ branch บริษัทขาดไฟล์เหล่านี้
- app/Database/Migrations/2026-11-10-160000_AddPrimaryFlagToAcademyPlayerEnrollments.php — เพิ่ม is_primary เมื่อยังไม่มี ค่าเริ่มต้น 0 ไม่มีการกำหนดทีมหลักย้อนหลัง และ down เก็บคอลัมน์ไว้เพื่อรักษาข้อมูล

ก่อน deploy ให้ตรวจ migrations ที่รอรันตามกระบวนการของบริษัทและทดสอบ migration ใน staging หากฐานข้อมูลมีคอลัมน์แล้ว migration จะข้ามการเพิ่ม หากเพิ่งเพิ่ม ให้ตรวจว่ารายการนักเตะเดิมยังแสดงทีมและตำแหน่งตามที่บริษัทคาดหวัง เพราะ migration ไม่ได้กำหนดทีมหลักย้อนหลัง

ทดสอบบน staging ผ่าน HTTPS ด้วยบัญชีที่มีสิทธิ์และภาพพาสปอร์ตจำลอง กดเลือกรูปหรือถ่ายรูป → สแกน → ตรวจข้อมูลในฟอร์ม → กรอกช่องบังคับ → บันทึก → ตรวจรายชื่อในอะคาเดมี ทดสอบภาพที่อ่านไม่ได้ว่าฟอร์มยังกรอกเองได้

แพ็กนี้ไม่รวม .env, ฐานข้อมูล, ภาพพาสปอร์ต และข้อมูลนักเตะ และยังไม่ได้ deploy หรือทดสอบบนเว็บจริง
