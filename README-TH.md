# Jootball Passport scanner

ฟอร์มล่าสุดใช้ Backend OCR ผ่าน PHP proxy และมีป๊อปอัปตรวจทานผลสแกน
ขั้นตอนติดตั้งอยู่ใน services/passport-scanner/README.md
public/js/passport-ocr เป็นไฟล์จากตัวอ่านในเบราว์เซอร์รุ่นก่อนหน้า ตัวสแกนปัจจุบันเรียก Backend

ก่อน deploy ให้เทียบไฟล์กับ branch บริษัท ทดสอบใน staging และตรวจ migration ที่รอรัน
migration is_primary เพิ่มคอลัมน์เมื่อยังไม่มี ค่าเริ่มต้น 0 ไม่มีการกำหนดทีมหลักย้อนหลัง และ down เก็บคอลัมน์ไว้
ตรวจว่านักเตะเดิมยังแสดงทีมและตำแหน่งถูกต้องหลัง migration

ทดสอบ HTTPS เปิดกล้อง เลือกรูป สแกน ตรวจป๊อปอัป นำข้อมูลลงฟอร์ม และบันทึกนักเตะ รวมถึงกรอกเองเมื่อสแกนไม่ผ่าน
การทดสอบ parser และ syntax ไม่ครอบคลุมการเปิดกล้องหรือบันทึกผ่านบัญชีบริษัท
